This repository contains the [Docker](https://docker.com/) build files and the
Go tool that produce the browser images for
[WebSummoner](https://websummoner.github.io/websummoner/). Prebuilt images are
published on [Docker Hub](https://hub.docker.com/u/websummoner).

Seven browsers are maintained: Chrome, Firefox, Edge, Opera, Brave, Yandex
Browser and WebKit (Safari).
